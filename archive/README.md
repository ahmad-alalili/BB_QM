# أرشيف غير مشغّل

الملف `legacy/index1.html.txt` هو الصفحة الإضافية التي كانت موجودة باسم `index1.html`
في جذر المشروع. نُقل إلى هنا مرجعًا تاريخيًا، وتبقى النسخة السابقة محفوظة في سجل Git.

أضيف الامتداد `.txt` حتى لا يُفتح كتطبيق منافس للواجهة الحالية. لا يحتوي مسار التشغيل
أي رابط إليه. لا تنقل ملفاته أو قواعده تلقائيًا إلى الموقع الحالي، ولا تستخدمه كنقطة
بداية؛ الصفحة الفعلية هي `index.html` في جذر هذه النسخة.
